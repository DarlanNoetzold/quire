Regex tutorial — how the filter works

The sources are searched with your keywords as usual. Then the regex filter keeps only the results whose title, abstract, authors or classification match the pattern. The filter is case-insensitive unless you uncheck "Ignore case"; ^ and $ match the start/end of each field (title, abstract, authors, classification), not of the whole text.

PatternMeaningMatches
abcLiteral text"abc"
a|ba OR b"cat" and "bat"
^deep / net$Start / end of a field"deep learning", "...network"
.Any single character"d.g" → "dig", "dog"
* + ?0+, 1+ or 0-1 times"colou?r" → "color", "colour"
[abc] / [a-z]One of the set"gr[ae]y" → "gray", "grey"
[^x]Anything except x"gr[^a]y" → "grey"
\d \w \sDigit / word char / whitespace"\d{4}" → any year
\bWord boundary"\bnet\b" — not "internet"
(ab|cd)Group with alternatives"crypto(graphy|currency)"
{n,m}Repeat n to m times"\w{4,8}"

Ready-made examples:

  • ^deep — titles starting with "deep"
  • learn\w* — learning, learner, learned…
  • \btransformers?\b — the whole words "transformer" / "transformers"
  • attention.*(lstm|cnn) — "attention" followed by "lstm" or "cnn"
  • smith \w+, john d\. — authors named "Smith John D."

If the pattern is invalid, the filter is ignored and a warning is shown. To test and learn more, see regex101.com.
